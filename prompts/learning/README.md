# Learning Prompts

## Tutor Mode

Best for: learning a concept without passive reading.

```text
Teach me [topic].

My level:
[beginner/intermediate/advanced]

Goal:
[what I want to do with it]

Teach in this format:
1. Simple explanation
2. Concrete example
3. Common misconception
4. Practice question
5. Feedback on my answer

Ask me one question at a time.
```

## Skill Plan

Best for: building a learning roadmap.

```text
Create a learning plan for [skill].

Current level:
[level]

Time available:
[hours/week]

Goal:
[specific outcome]

Constraints:
[budget/tools/deadline]

Create:
- 30-day plan
- Weekly milestones
- Practice projects
- Resources to look for
- How to test progress
```

## Explain From My Notes

Best for: turning notes into understanding.

```text
Help me understand these notes.

Notes:
[paste notes]

Do:
- Organize the ideas
- Explain confusing parts
- Define key terms
- Create examples
- Give me 10 quiz questions
- Identify what I should study next
```

## Interview Prep

Best for: preparing for a role or exam.

```text
Prepare me for [interview/exam/topic].

Context:
- Role/topic: [details]
- My background: [background]
- Weak areas: [weak areas]

Create:
- Likely questions
- Strong answer frameworks
- Practice drills
- Mock interview with feedback
- Final review checklist
```
