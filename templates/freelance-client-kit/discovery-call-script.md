# Discovery Call Script

Purpose: diagnose whether the problem is valuable enough to justify paid work.

## Opening

```text
Thanks for taking the time. I want to understand the workflow and whether a small pilot makes sense. If it does not, I will say that directly.
```

## Questions

- What triggered the need now?
- What happens if this stays the same for 90 days?
- How are you solving it today?
- Where does the current process break?
- How often does this happen?
- Who is affected by it?
- What would a useful first version look like?
- What would make this not worth doing?
- Who needs to approve the next step?

## Transition

```text
Based on what you shared, I would not start with a large project. I would start with [pilot], deliver [specific result], and then decide if the larger rollout is worth it.
```

## Close

```text
I can send a short proposal with scope, timeline, and price. If it looks right, we can start with the pilot this week.
```
