# Freelance Client Prompt Stack

Use this stack to land freelance clients with a focused offer, a proof asset, specific outreach, and disciplined follow-up.

The goal is not to automate spam. The goal is to use AI to research faster, diagnose better, write sharper messages, and turn a vague skill into a client-ready system.

## 1. Niche Selector

Best for: choosing a buyer segment you can reach and serve quickly.

```text
Help me choose a freelance niche for the next 14 days.

My skills:
[skills]

Proof I can show:
[screenshots, past work, samples, projects, repos, audits, case studies]

Possible buyers:
[buyer groups]

Analyze each niche by:
- Urgent pain
- Budget likelihood
- Buyer access
- Proof speed
- Competition
- First offer potential
- Retainer potential

Output:
- Score table from 1-5
- Best niche to test
- Why this niche wins
- 10 pain phrases buyers likely use
- 30 prospect search queries
- One fixed-scope service idea
```

## 2. Service Wedge Builder

Best for: turning a broad skill into a clear offer.

```text
Turn this broad freelance skill into a productized service wedge.

Skill:
[skill]

Target buyer:
[buyer]

Pain:
[pain]

Constraints:
- The first version must be manually deliverable in 3-5 days.
- The buyer must understand the result in 10 seconds.
- It must lead naturally to a larger project or retainer.

Create:
- One-sentence offer
- Deliverables
- Scope boundary
- What is out of scope
- Starter price
- Standard price
- Retainer path
- Proof asset to create
- Common objections
- Short sales page section
```

## 3. Proof Asset Generator

Best for: creating something useful before asking for a call.

```text
Create a proof asset that helps me land freelance clients.

Target buyer:
[buyer]

Service:
[service]

Public example or context:
[link, screenshot, page copy, workflow, chatbot, listing, job post, content asset]

Create:
- 5 specific issues or opportunities
- Business impact for each
- Recommended fix
- Before/after structure
- One-page PDF outline
- 60-second Loom script
- Outreach message that asks permission to send it

Tone:
Useful, specific, non-roasty, and professional.
```

## 4. Prospect List Builder

Best for: building a small, high-quality list instead of blasting strangers.

```text
Design a prospect list for this freelance offer.

Buyer:
[buyer]

Offer:
[offer]

Best triggers:
[launches, hiring, new funding, poor reviews, broken page, new tool, new content, growth push]

Create:
- Ideal customer profile
- Disqualifiers
- Buyer job titles
- Search queries for LinkedIn, Google, Upwork, directories, job boards, and communities
- Spreadsheet columns
- Personalization fields
- 5 segment examples
- Lead score from 1-5
- 100-prospect list building workflow
```

## 5. Specific Outreach Writer

Best for: messages that do not sound AI-generated.

```text
Write concise freelance outreach.

Prospect:
[company/person]

Specific trigger:
[what I noticed]

Likely business impact:
[why it matters]

Offer:
[offer]

Proof asset:
[proof asset]

Constraints:
- Under 75 words
- No fake flattery
- No hype
- No long intro
- One clear question
- It should sound like one human wrote to one other human

Create:
- 5 message variants
- Best subject line or DM opener
- Follow-up 1 with new value
- Follow-up 2 close-the-loop message
- Why each version might work
```

## 6. Upwork Proposal Analyzer

Best for: avoiding wasted Connects and writing diagnosis-first proposals.

```text
Analyze this Upwork job before I apply.

Job post:
[paste job]

My service:
[service]

Relevant proof:
[proof]

Analyze:
- Fit score from 1-10
- Budget risk
- Client clarity
- Red flags
- What the client probably really needs
- First 2 lines of the proposal
- 120-word proposal
- Best attachment to include
- One smart question
- Whether I should apply or skip
```

## 7. LinkedIn Profile Converter

Best for: making a profile work like a focused landing page.

```text
Rewrite my LinkedIn profile to land freelance clients.

Target buyer:
[buyer]

Service:
[service]

Proof:
[proof]

Current profile:
[paste headline/about/featured]

Create:
- 10 headline options
- About section
- Featured section plan
- LinkedIn Service Page copy
- 3 pinned post ideas
- CTA
- Keywords to include naturally
- What to remove because it creates confusion
```

## 8. Discovery Call Script

Best for: diagnosing value before pitching.

```text
Create a discovery call script for this freelance service.

Buyer:
[buyer]

Offer:
[offer]

Likely pain:
[pain]

Create:
- Opening
- Context questions
- Business value questions
- Current workflow questions
- Budget/timing questions
- Red flags
- How to transition to recommendation
- Closing language
- Post-call recap email
- When to propose a paid pilot instead of a large project
```

## 9. Proposal Builder

Best for: sending a decision document, not a brochure.

```text
Write a freelance proposal.

Discovery notes:
[notes]

Buyer problem:
[problem]

Recommended scope:
[scope]

Price:
[price]

Create:
- Executive summary
- Problem in the buyer's words
- Recommended solution
- Deliverables
- Timeline
- Assumptions
- Out-of-scope items
- Optional upgrade
- Payment terms
- Next step
- Follow-up email
```

## 10. Follow-Up CRM

Best for: turning ignored messages and old conversations into calls.

```text
Build a follow-up system for my freelance leads.

Offer:
[offer]

Lead rows:
[paste companies, contacts, trigger, status, notes]

Create:
- CRM columns
- Status definitions
- Next-step rules
- Follow-up sequence
- Reactivation message
- Close-the-loop message
- Weekly review checklist
- Metrics to track

Rule:
Every follow-up needs a useful reason, not "just checking in."
```

## 11. 14-Day Client Sprint

Best for: execution when you have no momentum.

```text
Create a 14-day sprint to land my first or next freelance client.

My niche:
[niche]

My offer:
[offer]

Available proof:
[proof]

Available time per day:
[time]

Create:
- Daily tasks
- Exact deliverables
- Number of prospects/messages/posts
- Scripts for each day
- What to measure
- Decision rules if replies are low
- How to improve the offer after day 7
```

## Quality Checklist

- Does the prompt include a specific buyer?
- Does it include a specific business pain?
- Does it request proof, not just copy?
- Does it produce a deliverable you can use today?
- Does it avoid mass-spam or fake personalization?
- Does it include a next step and a metric?
