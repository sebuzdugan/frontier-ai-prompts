# Daily Work Prompts

## Inbox Reply

Best for: turning messy context into a clear reply.

```text
Help me reply to this message.

Context:
- Relationship to recipient: [manager/client/friend/vendor/etc.]
- Goal of reply: [inform/decline/negotiate/confirm/request/etc.]
- Tone: [warm/direct/brief/professional/etc.]
- Important facts: [facts]
- Message to reply to:
[paste message]

Draft 3 options:
1. Short and direct
2. Warm and polished
3. Firm but respectful

Then recommend the best one and explain the tradeoff in one sentence.
```

## Decision Brief

Best for: making a choice when you have tradeoffs.

```text
Help me decide between these options:
[option A]
[option B]
[option C]

Decision context:
- Goal: [goal]
- Constraints: [time/budget/risk/quality]
- What matters most: [criteria]
- What I already know: [notes]

Create a decision brief with:
- Recommendation
- Why this is the best option
- Main risks
- What would change your recommendation
- Next 3 actions
```

## Meeting Prep

Best for: preparing quickly before a call.

```text
Prepare me for this meeting.

Meeting:
- Topic: [topic]
- Attendees: [people/roles]
- Desired outcome: [outcome]
- Background notes: [notes]

Give me:
- 5 likely discussion points
- Questions I should ask
- Points I should be ready to defend
- A concise opening statement
- A follow-up email template
```

## Weekly Reset

Best for: turning scattered tasks into a sane plan.

```text
Help me plan this week.

Inputs:
- Current projects: [list]
- Deadlines: [list]
- Loose tasks: [list]
- Energy/time constraints: [notes]

Create:
- Top 3 outcomes for the week
- Must-do list
- Nice-to-do list
- Things to defer or delete
- Day-by-day plan
- Risks to watch
```
