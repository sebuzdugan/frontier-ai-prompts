# Contributing

This repo is for practical prompts that people can use immediately.

## Add a Prompt

Use this format:

```markdown
## Prompt Name

Best for: [one sentence]

```text
[prompt]
```

Quality check:
- [ ] The prompt states the task clearly.
- [ ] The prompt includes placeholders for context.
- [ ] The prompt defines the output format.
- [ ] The prompt includes a verification step when quality matters.
```

## Good Prompt Rules

- Prefer reusable structures over clever wording.
- Ask for the real output, not just brainstorming.
- Include context, audience, constraints, examples, and desired format.
- For current reasoning models, do not over-script every internal step. Give goals and success criteria.
- For faster models, be more explicit and include examples.
- Do not include private data, keys, credentials, or confidential customer information.
- Do not copy large prompts from external repositories unless their license clearly permits it and attribution is included.

## Source Links

When a prompt is adapted from a public technique, add a short note and link in `resources/source-notes.md`.
