# Research Prompts

## Research Brief

Best for: synthesizing a topic with source discipline.

```text
Create a research brief on [topic].

Research question:
[question]

Audience:
[audience]

Scope:
- Include: [scope]
- Exclude: [scope]
- Time period: [dates]

Requirements:
- Use credible and current sources.
- Separate facts from interpretation.
- Flag uncertainty and disagreements.
- Include source links for important claims.

Output:
- Executive summary
- Key findings
- Evidence table
- Risks or caveats
- Recommended next steps
```

## Source Evaluator

Best for: deciding whether to trust a page, paper, or claim.

```text
Evaluate this source.

Source:
[paste link/text]

Claim I care about:
[claim]

Assess:
- Author/publisher credibility
- Evidence quality
- Date and freshness
- Conflicts of interest
- What the source proves
- What it does not prove
- Better sources to check next
```

## Compare Options

Best for: choosing a tool, vendor, model, or approach.

```text
Compare these options:
[option list]

Use case:
[your use case]

Criteria:
[price/quality/speed/privacy/integrations/etc.]

Create:
- Comparison table
- Best option for my use case
- Best budget option
- Best premium option
- Hidden tradeoffs
- Questions I should answer before deciding
```

## Deep Synthesis

Best for: understanding a complex issue from many inputs.

```text
Synthesize these materials into a coherent view.

Materials:
[paste notes/sources/transcripts]

Goal:
[what you need to understand or decide]

Output:
- Main thesis
- Supporting arguments
- Counterarguments
- Timeline if relevant
- Open questions
- Actionable implications
```
