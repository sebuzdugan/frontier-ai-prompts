# 14-Day Freelance Client Sprint

Goal: create one paid pilot or enough evidence to improve the niche, offer, and outreach.

## Day 1: Pick the niche

- Choose one buyer group.
- Collect 10 pain phrases from jobs, posts, reviews, or communities.
- Define one fixed-scope service wedge.
- Write the one-sentence offer.

## Day 2: Build proof

- Pick one public example.
- Create a one-page audit, rewrite, workflow map, or before/after.
- Record a 60-90 second Loom.
- Save the proof link in the lead tracker.

## Day 3: Fix your client surface

- Rewrite LinkedIn headline.
- Update About section.
- Add proof to Featured.
- Add the GitHub prompt stack link where relevant.

## Day 4: Build the list

- Add 30 prospects with trigger, source, likely pain, and contact path.
- Remove weak fits.
- Segment into 2-3 groups.

## Days 5-9: Send and post

- Send 10 researched messages per day.
- Publish one proof-based post per day.
- Track replies and objections.
- Do not change the offer until you have 30-50 sends.

## Day 10: Improve the offer

- Review replies.
- Rewrite the first line.
- Tighten the deliverable.
- Create one better proof asset if needed.

## Days 11-12: Calls and proposals

- Run discovery calls.
- Sell a fixed-scope pilot first.
- Send proposals within 24 hours.

## Days 13-14: Follow-up and decide

- Follow up with useful proof, not pressure.
- Close the loop on non-responders.
- Decide: continue niche, adjust offer, or change channel.
