# XML-Style Prompt Template

Useful with Claude and other models when you need to separate instructions from data.

```text
<task>
[What you want done]
</task>

<context>
[Background]
</context>

<inputs>
[Paste source material]
</inputs>

<constraints>
- [Constraint 1]
- [Constraint 2]
- [Constraint 3]
</constraints>

<success_criteria>
- [Criterion 1]
- [Criterion 2]
- [Criterion 3]
</success_criteria>

<output_format>
[Exact format]
</output_format>
```
