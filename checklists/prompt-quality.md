# Prompt Quality Checklist

Use this before saving or sharing a prompt.

- [ ] The prompt says exactly what task should be completed.
- [ ] It includes audience or user context.
- [ ] It includes constraints: tone, length, tools, deadline, format, or risk.
- [ ] It separates instructions from source material.
- [ ] It defines the output format.
- [ ] It asks for uncertainty or assumptions when facts matter.
- [ ] It includes a verification step for important work.
- [ ] It avoids asking for hidden chain-of-thought.
- [ ] It does not include secrets, private data, or credentials.
- [ ] It has been tested on at least one real example.

## Quick Fixes

If the answer is vague:

- Add examples.
- Add success criteria.
- Ask for a table or checklist.
- Provide more source context.

If the answer is too long:

- Set a word limit.
- Ask for executive summary first.
- Ask for only the top 3 recommendations.

If the answer is too generic:

- Add audience details.
- Add constraints.
- Add what you already tried.
- Ask for tradeoffs and specific next actions.
