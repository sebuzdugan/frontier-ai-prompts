# Upwork Proposal Template

## Fit check before applying

- Is the problem specific?
- Does the buyer mention context, goal, or examples?
- Is the budget realistic?
- Can you attach proof that matches the job?
- Can you diagnose the first step in two lines?

## Proposal

```text
Hi [name],

The main issue I see is [specific diagnosis from job post]. If that is right, I would not start with [wrong/overbuilt approach]. I would start by [first concrete step].

Relevant proof: [one sentence about matching proof].

My first pass would be:
1. [step one]
2. [step two]
3. [deliverable]

One question before scoping: [smart question that moves the project forward]?
```

## Attachment

Use one relevant proof asset:

- before/after
- Loom walkthrough
- sample audit
- one-page workflow map
- short case study

Do not attach a full generic portfolio unless requested.
