# Image Prompts

## Product Shot

Best for: clean commercial images.

```text
Create a product image prompt.

Product:
[product]

Audience:
[audience]

Use case:
[ad/website/social/thumbnail]

Style:
[minimal/luxury/technical/playful/etc.]

Must include:
[details]

Must avoid:
[details]

Write:
- Main image prompt
- Negative prompt or avoid-list
- 3 style variations
- Notes for aspect ratio and composition
```

## Thumbnail Concept

Best for: scroll-stopping but clean thumbnails.

```text
Design a thumbnail concept for:
[topic/title]

Platform:
[YouTube/X/LinkedIn/blog/etc.]

Audience:
[audience]

Emotion:
[curiosity/urgency/clarity/etc.]

Create:
- Visual concept
- Main focal point
- Text overlay options under 5 words
- Color and contrast direction
- Image generation prompt
```

## Style Guide Extractor

Best for: getting consistent images across a series.

```text
Create an image style guide.

Brand/topic:
[brand/topic]

Reference description or image notes:
[describe references]

Output:
- Visual style
- Color palette
- Lighting
- Composition rules
- Subject rules
- Things to avoid
- Reusable image prompt template
```
