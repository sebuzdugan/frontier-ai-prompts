# Core Prompt Template

```text
You are helping me complete [task].

Context:
- Goal: [what success looks like]
- Audience: [who this is for]
- Inputs: [paste notes, data, draft, code, links, transcript, screenshots]
- Constraints: [tone, length, deadline, budget, brand, format, tools]
- Non-goals: [what not to do]

Work process:
1. Identify missing assumptions.
2. Choose the best approach.
3. Produce the deliverable.
4. Check the deliverable against the goal and constraints.

Output format:
[format]
```
