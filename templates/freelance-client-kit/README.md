# Freelance Client Kit

Companion templates for the [Freelance Client Prompt Stack](../../prompts/freelance-clients/README.md).

Use these files with the 38-page AI Freelance Client Playbook:

1. Start with `14-day-client-sprint.md`.
2. Track prospects in `lead-tracker.csv`.
3. Use `cold-outreach-scripts.md` to send researched messages.
4. Use `loom-audit-script.md` when a visual proof asset will help.
5. Use `upwork-proposal-template.md` for high-intent marketplace jobs.
6. Use `discovery-call-script.md` before pricing.
7. Use `proposal-template.md` to close a fixed-scope pilot.

The system is intentionally manual-first. Automate only after the offer gets replies.
